# 🧮 حاسبة تكلفة المشاريع التفاعلية | Interactive Project Pricing Calculator

أداة SaaS تفاعلية لحساب تكلفة ومدة تنفيذ مشاريع الويب فورياً بناءً على الخيارات والميزات الإضافية المختارة.

---

## 🚀 المميزات الرئيسية (Key Features)

* **حساب لحظي متجاوب (Real-time Live Calculation):** تحديث السعر النهائي والمدة الزمنية فورياً مع كل تفاعل.
* **عناصر التحكم المخصصة (Custom UI Controls):** تشمل بطاقات اختيار راديو مخصصة، سلايدر نطاق ديناميكي، وقوائم الميزات الإضافية.
* **تصميم عصري متطور (Modern Dark Glassmorphism):** واجهة مستخدم ناعمة بالوضع الداكن تعطي طابع تطبيقات الـ SaaS الاحترافية.
* **كود نظيف ومنظم (Clean & Lightweight JS):** مكتوب باستخدام Vanilla ES6 بدون أي مكتبات ثقيلة لتأمين أداء فائق.

---

## 🛠️ التقنيات المستخدمة (Tech Stack)

* **HTML5:** بناء الهيكل التفاعلي واستخدام HTML Form Controls.
* **CSS3:** استخدام CSS Variables, Flexbox, CSS Grid, و Custom Range Styling.
* **JavaScript (Vanilla ES6+):** إدارة الأحداث (Event Handling) ومنطق الحسابات اللحظي.
